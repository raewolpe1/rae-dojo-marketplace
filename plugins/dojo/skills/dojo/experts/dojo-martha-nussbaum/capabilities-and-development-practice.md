# Capabilities and Development Practice

## When to Use
- When operationalising the capabilities framework in development programming.
- When designing M&E that uses capabilities.
- When integrating capabilities with other development tools.

## Fails When
- **The framework is treated as a measurement checklist.** It is a normative framework that supports measurement, not a measurement instrument.

## Core Concept

Translating the capabilities approach from political philosophy into development practice has been substantial work. UNDP's HDI, the Multidimensional Poverty Index (MPI), the OPHI work on capabilities measurement, and many country-specific applications have developed practical instruments.

**The practical translation involves several steps:**

**1. Selection of relevant capabilities.** Each context requires specification of which capabilities are most pressing. The Nussbaum list provides structure; the operational selection is contextual.

**2. Specification of indicators.** Each capability requires concrete indicators that approximate it. For bodily health: nutrition, access to health services, child mortality, maternal mortality. For senses-imagination-thought: education levels, literacy, school completion. For practical reason: indicators of decision-making freedom, particularly within household and community.

**3. Threshold definition.** For each indicator, what level represents the capability threshold? This is contextual and partly political — democratic public reasoning has a role.

**4. Disaggregation.** Capability assessment requires disaggregation by gender, race, geography, age, disability. Aggregate scores hide deprivation.

**5. Integration with existing tools.** Capabilities can be integrated with cost-benefit analysis (as supplement, not replacement), with logical frameworks (using capability targets), with theory-of-change models (linking interventions to capability outcomes).

**6. Use in policy.** The framework supports specific policy choices: prioritising capabilities below threshold; designing programmes that address multiple capabilities together; evaluating programmes by capability outcomes.

**Examples of operationalisation:**

- The HDI's three dimensions (life expectancy, education, income) capture three capabilities partially. The MPI's ten indicators provide a fuller capability picture.
- Programme evaluations using capability frameworks distinguish between resource provision (input), service delivery (process), capability acquisition (outcome).
- M&E frameworks can use capability indicators alongside conventional measures, providing a richer picture of development impact.

**Common implementation challenges:**

- Measurement difficulty for some capabilities (emotions, practical reason, play). Proxies are imperfect.
- Aggregation difficulty across capabilities. The non-tradability claim creates conceptual challenges.
- Threshold ambiguity. What threshold is appropriate is contested.
- Political-economy resistance. The framework's demands can be uncomfortable for governments and donors.

**The framework supplements rather than replaces conventional development practice.** Cost-benefit analysis, logframes, results-based management, RCTs all have their roles. The capabilities framework provides a normative anchor that prevents these tools from drifting away from what fundamentally matters — human flourishing in the multiple dimensions captured by the central capabilities.

**The South African operational context.** The country has policy frameworks (NDP 2030, sectoral plans) that engage capability-relevant outcomes — education, health, employment, voice — but typically without an explicit capabilities-justice anchor. Building this anchor explicitly would support more coherent prioritisation, particularly across the gender and disability dimensions that the framework foregrounds.

**For M&E consultants specifically.** The capabilities framework provides a substantive answer to "what should we measure?" and "what counts as success?" The answers are: measure capability acquisition across the central capabilities, disaggregated by relevant categories; success is reaching the threshold on each capability for each person. This is more demanding than typical M&E but supports stronger evaluative judgments.

## How to Apply

1. **Use the capabilities list as the framework structure** for M&E design.
2. **Develop context-specific indicators and thresholds** through democratic reasoning.
3. **Disaggregate assessments** by gender, race, geography, age, disability.
4. **Combine with conventional tools** rather than displacing them.

## Examples

**Situation:** Designing M&E for a South African rural-development programme.

**Application:** The capabilities framework: bodily health (water, food, healthcare access); bodily integrity (gender-based-violence indicators, safety from crime); senses-imagination-thought (education quality, literacy); affiliation (social inclusion, freedom from discrimination); control over environment (political voice, property rights, livelihood security). Indicators specified contextually; thresholds defined through public reasoning; results disaggregated by gender, race, disability. The M&E captures multidimensional impact and surfaces capability deprivation that aggregate measures would hide.

**Result:** An M&E framework that supports substantive evaluative judgments grounded in justice claims.

## Anti-Patterns

**Don't:** Reduce capabilities to a measurement checklist.
**Why:** The framework supports measurement but exceeds it.

**Don't:** Use the framework as window-dressing on conventional M&E.
**Why:** Real application requires substantive engagement with the normative claims.

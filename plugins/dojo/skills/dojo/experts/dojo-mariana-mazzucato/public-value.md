# Public Value

## When to Use
- When public spending is being framed as a cost against private wealth creation.
- When the value created by public goods, infrastructure, and missions is being under-recognised.
- When designing public-sector evaluation frameworks.

## Fails When
- **The specific public activity is genuinely wasteful** — public value is not a defence of all public spending.

## Core Concept

Public value is the value created by public goods, public infrastructure, public capability, and public-purpose missions that is not captured in private-sector accounting. The orthodox framing treats public spending as a cost subtracted from private wealth creation; public value reframes much of public spending as value creation in its own right.

The framework rests on several observations:

**Public goods produce value.** Defence, infrastructure, basic research, education, healthcare, environmental protection, the legal system — these produce value that the private economy depends on. They are not free; they are paid for through taxation. Their value is not captured in private accounting but is real.

**Public infrastructure underlies private productivity.** Roads, ports, power grids, water systems, telecommunications, schools, hospitals — private productive activity depends on these. The "private" GDP figure measures value that depends on public investment.

**Public capability matters.** State capacity to deliver services, regulate effectively, coordinate complex projects, and execute missions is a productive asset. It is built through sustained investment in public-sector talent, organisational design, and institutional development.

**Mission-oriented activity creates value beyond accounting measurement.** The climate transition, public health improvements, social mobility, regional development — these are missions that create value distributed across society in ways national accounts do not capture.

The implications:

**Public spending evaluation should reflect public value created**, not just costs incurred. Cost-benefit analysis that treats public spending as cost only is methodologically deficient.

**Public-sector strategy should be designed for value creation**, not for cost minimisation. The cost-minimisation framing has hollowed out public capability across many developed and developing economies.

**Public-private accounting** that treats only private as value creation is empirically false. The integrated picture credits both with their real contributions.

For developing countries: defending public sector capability, infrastructure investment, and mission-oriented activity requires the public value framing. The orthodox cost-cutting framing has produced under-investment and capability erosion across many middle-income countries.

## How to Apply

1. **Reframe public spending evaluation** to include value created, not just cost incurred.
2. **Defend public capability investment** on public-value grounds.
3. **Use mission frameworks** to organise public-value creation.
4. **Resist cost-cutting framings** that ignore public-value creation.

## Examples

**Situation:** South Africa's public-sector reform debates treat public capability building as cost.

**Application:** Reframe. Building public-sector capability for industrial policy delivery, JET implementation, infrastructure management, social service delivery creates public value substantially exceeding the costs. The current low-capability equilibrium produces enormous public-value losses. Investment in public-sector talent, institutional design, and organisational capability is public-value creation.

**Result:** A public-sector reform programme oriented to capability building rather than to cost cutting.

## Anti-Patterns

**Don't:** Use the framework to defend all public spending.
**Why:** Some public spending is genuinely wasteful. The framework requires distinguishing value-creating from value-extracting public activity.

**Don't:** Apply it without measurement attempts.
**Why:** Public value is real but hard to measure. The framework should drive better measurement, not avoidance of measurement.
